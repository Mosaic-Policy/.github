# Mosaic Policy

Government-relations and policy tools for Mosaic and its clients.

We build software for organizing government-relations work, turning research into
reports, and supporting policy teams with practical tools.

**[Visit Mosaic](https://mosaicpolicy.com)**

## For Mosaic teammates

Start with the **[Mosaic Command Deck](https://github.com/Mosaic-Policy/mosaic-tw-index#readme)**:
our operating hub for project documentation, the registry, runbooks, planning briefs,
and cross-repo work.

Most Mosaic repositories and team documents are private. Sign in with an account
that has access to use the links below.

| Project | What it is for |
|---------|----------------|
| [Congressional Matrix](https://github.com/Mosaic-Policy/mosaic-tw-Congressional_Matrix) | Government-relations CRM |
| [Mosaic Reports](https://github.com/Mosaic-Policy/mosaic-reports) | Document and report generation |
| [Innovation Tracker](https://github.com/Mosaic-Policy/Innovation-Tracker) | AI feature auditing and research |
| [Congress Directory Toolkit](https://github.com/Mosaic-Policy/congress-directory-toolkit) | Congressional directory and Hill Day workflows |
| [Trade Report](https://github.com/Mosaic-Policy/Trade-Report) | Monthly trade and tariff reporting |
