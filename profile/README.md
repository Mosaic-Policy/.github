# Mosaic Policy

Government-relations and policy tooling for Mosaic and its clients.

## Start here

- **[Command Deck](https://github.com/Mosaic-Policy/mosaic-tw-index)** — org operating hub: registry, labels, queues, and cross-repo work.
- **[Congressional Matrix](https://github.com/Mosaic-Policy/mosaic-tw-Congressional_Matrix)** — GR CRM (product).
- **[mosaic-reports](https://github.com/Mosaic-Policy/mosaic-reports)** — document / report generation toolkit.
- **[Innovation Tracker](https://github.com/Mosaic-Policy/Innovation-Tracker)** — AI feature auditor.
- **[Congress Directory Toolkit](https://github.com/Mosaic-Policy/congress-directory-toolkit)** — Hill Day / directory field toolkit.
- **[Trade Report](https://github.com/Mosaic-Policy/Trade-Report)** — CFA monthly trade/tariff pipeline.

## How we work

Classification lives in the Command Deck registry (`tier`, `lifecycle`, `owner`, `sensitivity`) and is mirrored as GitHub custom properties and topics. Cross-repo priorities roll up on the org **Mission Control** project.

Default issue/PR templates and reusable workflow templates for new repos live in this `.github` repository.
