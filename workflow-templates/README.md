# Workflow template availability

No reusable GitHub Actions workflow templates are published in this directory yet.
The organization profile and default pull request template are available in this repository.

For current repo setup and CI guidance, teammates should use the Command Deck's
[repo baseline](https://github.com/Mosaic-Policy/mosaic-tw-index/blob/main/standards/repo-baseline.md)
and [templates](https://github.com/Mosaic-Policy/mosaic-tw-index/tree/main/standards/templates).
These team documents require repository access.

When publishing a workflow template here, include its accompanying `.properties.json`
metadata so GitHub can offer it when a teammate creates a workflow. Follow
[GitHub's workflow template documentation](https://docs.github.com/en/actions/how-tos/reuse-automations/create-workflow-templates).
